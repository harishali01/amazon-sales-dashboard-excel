# amazon-sales-dashboard-excel
Interactive Excel dashboard using pivot tables, charts and slicers


An interactive sales dashboard built in Excel using pivot tables, charts and slicers.

## Dataset
500 orders (sample data) with category, product, payment method, state, rating and delivery rating.

## Key Metrics
- Total sales: 23.0M
- Total orders: 500
- Total quantity: 2.3K
- Average rating: 4.12
- Average delivery rating: 4.29

## Insights
- Electronics makes up about 76% of total sales.
- AirPods Pro is the top-selling product.
- December is the peak month, November the lowest.
- Karnataka has the highest share of sales (23%).
- Payments are spread almost evenly across UPI, Net Banking, Card and Cash.

## Tools Used
Excel (Pivot Tables, Slicers, Charts)
